# SmoothRadio 1.0.1

## Neu

- **Songtitel auch für HLS-Sender** — SmoothRadio findet automatisch einen MP3-Spiegel mit ICY-Metadaten. Funktioniert z. B. mit **WDR 2 Ostwestfalen-Lippe** und vielen anderen ARD-/HLS-Streams.
- **HLS-Badge** statt „UNKNOWN" in Senderkarten, Hero und Player.
- **Robustere Metadaten** — laufende ICY-Anfragen werden sauber abgebrochen und neu verbunden; Titel erscheinen deutlich schneller.
- **Weiterhören behält den Titel** — wird derselbe Sender erneut gestartet, bleibt der bereits ermittelte Song sichtbar.

## Installation

- **Installer**: `SmoothRadio-1.0.1-x64.exe` — per Benutzer, ohne Adminrechte
- **Portable**: `SmoothRadio-1.0.1-Portable.exe` — ohne Installation

Nicht code-signiert. Windows SmartScreen ggf. über *Weitere Informationen → Trotzdem ausführen* bestätigen.

## Discord RPC

Eigene Application-ID unter https://discord.com/developers/applications anlegen und in den Einstellungen eintragen. Optional das Asset `logo` hochladen (`resources/discord-logo.png`).
